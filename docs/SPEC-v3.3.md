# ALPHA SHIELD v3.3 (6-1-F) — 개정 스펙 요약

2026-11-27 KST 개정안. v3.2(`docs/SPEC-v3.2.md`)에서 바뀐 부분만 정리한다.
수치의 단일 출처는 `config/strategy.yaml` · `config/guards.yaml` 이고, 이 문서는 그 규칙의 근거·의도다.
백테스트 기준값(2년 +48.68%, MDD -10.18%, 샤프 2.05)은 v3.3 개정 전 수치이며, 수치를 바꾸면 무효가 된다.

## 1. 자금·사이징 (권장안 A 기본, `capital.plan`)

| 자산 | 1회 진입 | 종목 상한 |
|---|---|---|
| `$400` 미만 | `$75` | `$150` |
| `$400 ~ $500` 미만 | `$85` | `$170` |
| `$500` 이상 | `$120` | `$240` |

- 현금 안전 버퍼 `max(자산 × 15%, $55.00)` 상시 보존, `$10` 미만 주문 금지.
- 대안 B(`capital.plan: B`): `$500` 미만은 `$85 / $170` 단일 구간을 유지하고, 두 번째 종목 물타기는
  `min($85, 가용현금 − 안전버퍼)` 로 제한(최소 주문 미만이면 스킵).

## 2. 계좌 규정 가드와 판단 우선순위

- **현금 계좌**: 매도대금 T+1 결제. 미결제 대금을 뺀 결제 완료 현금으로만 사이징하고, 동일 종목 재매수를 차단(GFV 방지).
- **마진 계좌**: 자산 `$25,000` 미만에서 5영업일 내 당일 매수·매도 3회 도달 시 그날 신규 진입 중단(PDT 방지).
- 판단 우선순위: **(1) 계좌 Kill Switch → (2) 매도 → (3) 매수(신규·물타기)**.

## 3. 슬롯 순위(Hark 2)와 비정상 급락 가드

- `점수 = 알파 가중치 × min(|낙폭| ÷ |진입 임계|, 2.5)` — 낙폭 비율 2.5배 상한 캡.
- 장중 고점 대비 `-3.0 × ATR(20)%` 초과 폭락 종목은 **당일 신규 매수 대상에서 제외**(뉴스·공시 미탐지 돌발 악재).

## 4. 진입·물타기·손절·쿨다운

- 신규 진입: `-0.52 × ATR(20)%` 눌림 + `RSI(2) ≤ 15` + `주가 ≥ SMA200 × 0.95` (기존 0.80 → 0.95, 설정값).
- 물타기: 평단 대비 `max(1.5%, 0.8 × ATR(20)%)` 이상 하락 + `RSI(2) ≤ 35` + **1차 진입 후 최소 2시간(또는 익거래일)** · 종목당 1회.
- BUY 신호: 생성 후 15분(900초) 만료, 재전달 전 최신 `RSI(2) > 25` 또는 **미확인**이면 폐기(fail-closed).
- 손절: 단일 `-5.0%` / 물타기 `-3.5%`. **동일 종목 손절 시 당일 재진입 금지(EOD 쿨다운)** 복원.
  일반 청산 후 재진입 방지 15분(900초) 쿨다운은 유지.
- 시간청산: 10거래일(달력 14일) 만기에서 `+3.0%` 이상이면 즉시 청산하지 않고 **고점 대비 `-2.0%` 트레일링**으로 전환(옵션).

## 5. 15:00 소수점 마감 프로토콜과 프리마켓

- 개장 유예(09:30~09:45 ET)와 마감 전 15분(14:45~15:00 / 조기폐장 12:45~13:00 ET)은 **신규 매수·물타기 전용**.
- 보유 종목 오버나잇 갭하락 손절은 **09:32 ET 이후** 집행.
- **14:50~14:58 ET**(조기폐장 12:50~12:58 ET) 선제 청산:
 ① 만기 종목 일괄, ② 손절선 0.5%p 이내 근접 종목(단일 `-4.5%` 이하 / 물타기 `-3.0%` 이하).
- `ALLOW_FRACTIONAL_PREMARKET_SELL`(기본 `False`, 토스 기본값): 미지원이면 프리마켓 청산 신호를
  **09:30~09:32 ET 예약 매도 큐**로 넘겨 개장 직후 집행한다.
- 조기폐장일 소수점 주문 마감은 13:00 ET (정규장 종료 1시간 전 규칙을 적용하지 않는다 — 스펙 명시).

## 6. 데이터 안전장치와 계좌 Kill Switch

- `SMA200` 미확인: 매수 fail-closed / 매도 fail-open. 현재가 시세 15분 지연·결측: 매수 fail-closed.
- 매도 시 직전 5분봉 대비 `±10%` 이상 급변하면 보조 시세 크로스체크(이상 틱 가드) 통과 후 실행.
  보조 시세 미확인·불일치면 매도를 보류하고 알림(가짜 손절 방지).
- **계좌 Kill Switch(Safe Halt)**: 일일 손실(실현+미실현) `-4.0%` 도달 · 누적 MDD `-12.0%` 돌파 ·
  5분 내 동일 종목 중복 주문 시도 · API 3회 연속 오류 · 장부·실잔고 불일치 → **신규 주문 전면 정지 + 알림**.
  수동 해제(대시보드 킬스위치 OFF)만으로 재개된다.
